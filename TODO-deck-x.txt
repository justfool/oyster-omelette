# oyster-omelette Deck A / Deck B 待辦
# 格式： [ ] 未做   [~] 部分完成   [x] 已完成
# 範圍：2016 修訂版基本盒的 A＋B（官方 48 職業 + 48 次要改良）。
# 每張卡四欄：英文名、中文翻譯、效果、實現難易度 1～10。
# 難度是相對「現在這份程式」：規則在 game／actions／farmyard，動物還只記總數。
#
# 難度尺：
#   1  打出立刻結算，現有函式就能做
#   2  跟林務員同一套：用某格就多拿東西
#   3  看房型／人數／計分，不必改核心
#   4  回合格排程、簡單折扣、或額外一個小行動
#   5  替代費用、本回合記帳、或玩家要選項
#   6  卡上堆貨、行動鏈、或要看別人
#   7  改佔格規則，或家人／動物住在卡上
#   8  動物放到指定牧場、卡本身當田、或一次放兩個工人
#   9–10  要大改引擎；這 96 張最高只到 8
#
# 旅行卡：打出後交給左手（修訂版各牌庫 001–009）。
# 完整 Deck A／B 還要 Artifex／Bubulcus，列在文末，先不要開工。

================================================================
進度
================================================================
[ ] 卡表進程式：id、牌庫、種類、英文、中文、效果、難度、費用／前提、觸發
[ ] 開局改從 A＋B 基本套各抽 7 張（不再循環複製玩具卡）
[ ] Deck A 次要改良 0/24
[ ] Deck A 職業 0/24
[ ] Deck B 次要改良 0/24
[ ] Deck B 職業 0/24
[ ] 打出職業／次要改讀卡文，不要一律「打出就拿資源」
[ ] 旅行卡（A002／A005／A009／B002／B008）打出後交左手

建議開工順序：先難度 1～3，再 4～5。難度 7～8 等容量／佔格／工人重構後再做。

現有玩具卡（樵夫、大鍋菜…）先留著當測試樁，正式牌庫接上後再退役。
