# 畫面用詞（英文 → 中文）

畫面中文對齊 Board Game Arena 農家樂修訂版（2026-08-22 對過）。之後翻譯卡名、卡文、格名都先查這份，不要另發明一套。

- **卡規則與英文卡文**以 `database/agricola-database.csv` 的修訂版欄為準。
- **畫面上怎麼寫中文**以這份為準。
- 領域識別字（`forest`、`clay`、`fireplace_2`）不准改。
- 已綠的 feature 句子暫時不改。畫面字串在 `theme.SPACE_NAMES`、`MAJOR_NAMES`、`tui/`。

## 同名兩張：貴的加 `(*)`

火爐、壁爐各有便宜／貴兩張。名稱相同時，**貴的那張後面加 `(*)`**，不要把費用寫進名稱。

| bonus point(s) | 紅利分數 |
| accumulation space | 累積格 |
| action space | 行動格 |
| building resource(s) | 建築資源 |
| personal supply | 供應區 |

| returning home phase | 回家階段（不要寫結束階段） |

## 不做

- 不改領域 id、錯誤碼（`cannot_sow` 這類英文）。
- 不為了用語去改已綠的 feature 句子（之後若要改規格，另開增量）。
- 不把費用寫進卡名；同名兩張只用 `(*)` 標貴的。
- 卡費用、前提、效果數字以 CSV 為準，不要用社群卡表覆寫。
